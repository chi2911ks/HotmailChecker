**Hotmail Checker - By: CB Tool**
*Version: 1.0.0*
*Description: Check Microsoft account refresh token*

**How to use:**
1. Import accounts from a text file
2. Click "Start Check"
3. Wait for the results
4. Export live accounts

**Format:**
```
email|password|refresh_token|client_id
```

**Note:**
* The tool will check the refresh token and return the result
* Live accounts will be exported to a text file
